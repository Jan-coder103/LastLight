# Project context

Last Light is a single-player desktop browser survival and extraction game built with TypeScript and Three.js, with seeded regions, camp progression, and a scalable zombie horde.
Before starting a requested mission, read `plan.md`, `tracker.md`, and `HANDOFF.md`, then read the relevant sections of `README.md` and inspect the related source and tests.
Follow the phase status and owner-playtest gates in those files, and update the relevant documentation when the work changes project status or decisions.
